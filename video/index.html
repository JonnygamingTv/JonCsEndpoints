FFmpeg Command - Use only one audiostream

FFmpeg Command - Recommended for animation (HEVC)

FFmpeg Command - Mix multiple audiotracks
ffmpeg -i "./input.mkv" -map_metadata 0 -movflags faststart -s 1280:720 -filter_complex "[0:2]atrim=start=0:end=867,asetpts=PTS-STARTPTS[a1]; [0:1]atrim=start=867:end=870,asetpts=PTS-STARTPTS,volume=-10dB[jpclip]; [0:2]atrim=start=870,asetpts=PTS-STARTPTS[a2]; [a1][jpclip][a2]concat=n=3:v=0:a=1[outa]" -filter:v "subtitles='.\\input.mkv':si=0" -map 0:v -c:v h264_nvenc -preset slow -crf 20 -rc vbr -cq 22 -pix_fmt yuv420p10le -x265-params "pools=16:aq-mode=3:aq-strength=1.2:psy-rd=2.0:deblock=1,1" -map "[outa]" -c:a aac -b:a 224k -metadata:s:a:0 title="English (Enhanced)" -metadata:s:a:0 language=eng -c:s mov_text "./output.mp4"
